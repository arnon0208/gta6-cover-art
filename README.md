Neon Bay Cover Studio turns your photos and a caption into a GTA-style multi-panel poster — sunset and neon colour grades, four panel layouts, crop and position each photo by dragging, and a one-click PNG export in 1080 × 1080, 1080 × 1350 or 1920 × 1080. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory app
# open http://localhost:8080 — everything runs offline in the browser
```
